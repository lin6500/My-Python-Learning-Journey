### 项目 01：BMI 指数计算

**对应文件：** `function_bmi.py`

#### 3.1 功能目标

输入姓名、身高和体重，计算 BMI 指数，并根据计算结果输出对应的体重区间提示。

#### 3.2 实现思路

1.  定义 `fun_bmi()` 函数，接收姓名、身高和体重三个参数。
2.  检查身高和体重是否大于 0。
3.  根据 BMI 公式计算指数：BMI = 体重 /（身高 × 身高）。
4.  使用条件判断区分不同区间，并输出对应提示。
5.  在函数外调用两次，观察不同数据下的计算结果。

#### 3.3 核心代码

``` python
def fun_bmi(person, height, weight):
    if height <= 0 or weight <= 0:
        print("身高和体重必须大于0！")
        return

    print(person + "的身高：" + str(height) + "米")
    print(person + "的体重：" + str(weight) + "千克")

    bmi = weight / (height * height)
    print(person + "的BMI指数为：" + str(round(bmi, 2)))

    if bmi < 18.5:
        print("你这体型有点轻盈过头啦，快去吃点好吃的补一补！")

    if bmi >= 18.5 and bmi < 24.9:
        print("完美！你的身材管理很在线！")

    if bmi >= 24.9 and bmi < 29.9:
        print("最近伙食是不是有点太好了呀，适当运动一下吧！")

    if bmi >= 29.9:
        print("身体正在悄悄报警：该把减肥提上日程啦！")

    print("------------------------")


fun_bmi("路人甲", 1.83, 60)
fun_bmi("Lucy", 1.62, 50)
```

#### 3.4 涉及知识点

- 自定义函数与参数传递
- 数学运算
- `if` 条件判断

#### 3.5 运行结果

| 测试对象 |    身高 |    体重 |   BMI |
|----------|--------:|--------:|------:|
| 路人甲   | 1.83 米 | 60 千克 | 17.92 |
| Lucy     | 1.62 米 | 50 千克 | 19.05 |

程序能够根据不同计算结果输出相应的区间提示。

*注：BMI 区间按照课堂练习设定，仅用于程序学习与演示。*

### 项目 02：注意力实验反应时统计

**对应文件：** `attention_rt_summary.py`

#### 3.6 功能目标

模拟心理学注意力实验中的反应时数据录入。程序需要完成六次测试，判断数据是否处于有效范围，并计算有效数据的平均反应时。

#### 3.7 实现思路

1.  使用 `while` 循环控制六次数据录入。
2.  将小于 100 毫秒或大于 1500 毫秒的数据判定为无效。
3.  使用 `continue` 跳过无效数据。
4.  使用变量累计有效数据的数量和总和。
5.  如果存在有效数据，则计算平均值；如果没有，则输出提示。

#### 3.8 核心代码

``` python
times = 0
valid_count = 0
total = 0

print("注意力小测试开始啦！准备好了吗？")
print("接下来需要录入6次反应时，单位是毫秒。")
print("有效范围：100～1500毫秒")
print("------------------------")

while times < 6:
    reaction_time = float(input("请输入第" + str(times + 1) + "次反应时（毫秒）："))
    times += 1

    if reaction_time < 100 or reaction_time > 1500:
        print("这个数值有点超出范围啦，本次先不计入统计哦！")
        continue

    valid_count += 1
    total += reaction_time

print("\n六次录入结束，来看看结果～")
print("有效数据数量：" + str(valid_count))

if valid_count > 0:
    average = total / valid_count
    print("有效反应时的平均值是：" + str(average) + "毫秒")
    print("统计完成，辛苦啦！")
else:
    print("这次没有收集到有效数据，下次再试试吧！")
```

#### 3.9 涉及知识点

- `while` 循环
- `input()` 数据输入
- `if` 条件判断
- `continue` 语句
- 变量累加和平均值计算

#### 3.10 运行结果

测试数据：`450、99、600、4500、800、500`

其中，99 和 4500 毫秒被判定为无效数据，其余四次数据参与统计。

| 统计项目     |       结果 |
|--------------|-----------:|
| 总录入次数   |       6 次 |
| 有效数据数量 |       4 条 |
| 平均反应时   | 587.5 毫秒 |

*说明：程序使用 `float(input())` 接收数字形式的输入；如果输入字母等非数字内容，当前版本会出现输入转换错误。*
